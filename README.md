# 🪔 AI Diwali – Smart Festive Greeting Website

## About the Project
AI Diwali is an interactive festive greeting website created using HTML, CSS, and JavaScript. It combines traditional Diwali celebrations with a modern web experience.

## Features
- Personalized Diwali greetings using a name.
- Multiple greeting styles.
- Animated diya with a flickering flame.
- Fireworks animation.
- Greeting card display.
- Copy greeting feature.

## Technologies Used
- HTML – webpage structure
- CSS – styling and animations
- JavaScript – interactive features

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter a name and generate a greeting.
